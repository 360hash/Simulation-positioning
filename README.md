【软件简介】
一款免 Root 的 Android 模拟定位工具，用于测试自己开发的
应用/小程序中的定位相关功能（如支付宝小程序 my.getLocation）。
原理：利用 Android 官方 Mock Location 机制，将本应用设为
"模拟位置信息应用"后，通过 LocationManager 测试提供者向系统
注入坐标，全系统读取定位的应用都会拿到该坐标。

包名：com.fakeloc.app
适用：Android 9.0+（minSdk 28）
体积：约 2.6 MB（纯 Java，零第三方依赖）

--------------------------------------------------------
一、安装与启用（关键步骤）
--------------------------------------------------------
1. 安装 APK（FakeLoc-debug.apk）。

2. 打开一次本应用（无需任何操作，直接进地图）。

3. 开启开发者选项：
   设置 → 关于手机 → 连续点击"版本号"7 次。

4. 开发者选项 → 选择模拟位置信息应用 → 选择"模拟定位"。
   注意：本应用已在清单中声明 ACCESS_MOCK_LOCATION 权限，
   正常情况下会出现在列表里。

   ※ 如果列表里找不到本应用（部分国产 ROM 会隐藏/过滤）：
     用 ADB 直接写入开关（与列表选中完全等价，永久生效）：
       adb shell pm grant com.fakeloc.app android.permission.ACCESS_FINE_LOCATION
       adb shell appops set com.fakeloc.app android:mock_location allow
     验证：adb shell appops get com.fakeloc.app android:mock_location
     应输出 allow。撤销：adb shell appops reset com.fakeloc.app

5. 定位权限：打开应用不弹授权框；首次点击"开始模拟"或
   "模拟行走"时系统会弹出定位授权，请选择"使用应用时允许"。
   （Android 14+ 未授权定位时无法启动模拟。）

二、界面说明
--------------------------------------------------------
顶部中央：版权横幅（知识产权归 360HP 所有，不可商用）
左上角：🔍 搜索按钮（点击弹出搜索栏）
右上角：☰ 菜单按钮（点击弹出玻璃菜单）
右侧：+ / − 缩放按钮、◎ 回到我的位置
底部：纬度/经度显示 + [开始模拟] [停止模拟]
地图：单击选点（落标记并填入坐标），拖动浏览

--------------------------------------------------------
三、基本使用（固定模拟）
--------------------------------------------------------
1. 拖动地图到目标位置，单击地图选点（出现标记）。
2. 点底部 [开始模拟] → 状态变为"模拟中"。
3. 验证：打开地图类 App 或 GPS Test，定位应显示所选坐标。
4. 点 [停止模拟] 结束。

坐标说明：地图瓦片为高德 GCJ-02（火星坐标），注入系统前
已自动转换为 GPS 的 WGS-84，因此在高德/百度地图中显示位置
与所选点一致（误差 < 2 米），无需手动换算。

--------------------------------------------------------
四、模拟行走（多点路线）
--------------------------------------------------------
1. 右上角 ☰ 菜单 → 模拟行走 → 出现行走面板。
2. 在地图上依次单击多个途经点（显示编号 1/2/3… 和蓝色折线）。
3. 选择速度档：步行 1.4 m/s / 慢跑 3.0 m/s / 奔跑 5.5 m/s。
4. 点 [开始行走] → 角色沿路线依次走完所有节点，到达终点停止；
   状态栏显示"行走中/已到达"。
5. [清除路线] 可清空节点重新选点。

行走细节：坐标每秒更新，带 ±1.5m GPS 噪声、精度 3~9m 随机、
朝向随路线转向，速度字段=所选速度，模拟真实移动轨迹。

--------------------------------------------------------
五、菜单功能（右上角 ☰）
--------------------------------------------------------
· 模拟行走      —— 多点路线行走（见第四节）
· 收藏当前位置  —— 保存当前选点（本地存储）
· 我的收藏      —— 查看/点击收藏点，点击即选点
· 历史记录      —— 最近使用过的坐标，点击即选点
· 手动输入坐标  —— 直接输入经纬度选点（适合精确坐标）
· 回到我的位置  —— 地图定位到手机真实位置
· 清除标记      —— 移除地图上的选点标记
· 停止模拟      —— 结束模拟（同底部按钮）

--------------------------------------------------------
六、搜索功能（左上角 🔍）
--------------------------------------------------------
1. 点左上角 🔍 → 弹出玻璃搜索栏。
2. 输入地名（如"天安门"）→ 回车或点搜索。
3. 下拉显示搜索结果，点击某条 → 地图飞到该位置并选点。
4. 再点 🔍 收起搜索栏。

说明：搜索使用 Photon（OpenStreetMap 数据），无需 Key、
国内可直连；主要地标/道路可搜到，覆盖不如高德全。
如需高德级搜索，需申请高德 Web 服务 Key。

--------------------------------------------------------
七、常见问题
--------------------------------------------------------
Q1. 模拟后高德地图/支付宝小程序还是显示真实位置？
   高德、支付宝采用"混合定位"：GPS/网络定位走系统
   LocationManager（可被模拟），但基站+WiFi 网络定位走
   各自服务器（绕过模拟，免 Root 无法拦截）。
   对策：① 测试时关 WiFi+移动数据（飞行模式），逼其只用
   被模拟的 GPS；② 小程序改用官方开发者工具的"模拟定位"
   功能；③ 重启支付宝（my.getLocation 有定位缓存）。

Q2. 切到其他应用后模拟停止了？
   本版本为保证兼容性（真机不闪退）采用"无前台服务"架构，
   模拟依赖 App 进程存活。进程被系统回收后模拟即停止，
   回到应用重新点 [开始模拟] 即可。

Q3. 为什么 MuMu 模拟器上看到的坐标不对？
   MuMu 预装了第三方"模拟位置"应用，会持续注入成都坐标

   （30.58, 104.12）。判断谁在注入：adb shell dumpsys location
   看时间戳是否刷新，刷新的是活跃注入者。

Q4. 应用闪退？
   本版本已移除前台服务（Android 14+ 对 location 型前台服务
   严格，未授权定位即抛 SecurityException 导致闪退）。
   若仍异常，请确认：Android 9.0+、定位权限已授予、
   开发者选项中本应用未被禁用。

--------------------------------------------------------
八、卸载与清理
--------------------------------------------------------
直接卸载应用即可；模拟位置开关（appops）随卸载自动清除。
若曾用 ADB 设置，也可执行：
  adb shell appops reset com.fakeloc.app
